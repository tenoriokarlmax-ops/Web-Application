About Gauss

Gauss is a small workbench built around one method: Gauss–Jordan elimination. It has two calculators, a linear-system solver and a chemical equation balancer, and the balancer runs on the solver’s math. Every result comes with its reasoning, so it works for checking homework as well as for learning the method.

What is Gauss–Jordan elimination?

A system of equations is written as an augmented matrix: one row per equation, one column per variable, and a final column for the constants. Three legal row operations simplify it without changing its solutions:

  • Swap two rows.
  • Multiply a row by a nonzero number.
  • Add a multiple of one row to another.

The goal is reduced row echelon form (RREF): each pivot is 1 and is the only nonzero entry in its column. Then you can read the answer directly.

  1. Find a pivot. Pick the next column and choose the row with the largest entry.
  2. Make it 1. Divide the pivot row by the pivot.
  3. Clear the column. Subtract multiples of the pivot row from every other row.
  4. Repeat for the next column, then read the result.

A row like 0 0 | 5 means no solution. Fewer pivots than variables means infinitely many solutions.

How the chemical balancer works

Atoms are conserved, so each element gives one linear equation: atoms on the left equal atoms on the right. Gauss builds a matrix of element counts (products count as negative), reduces it with Gauss–Jordan, and reads the coefficients from the one free variable. It then scales them to the smallest whole numbers. Open any balanced result in the solver to see the same matrix. See more uses on the real-world uses page.
